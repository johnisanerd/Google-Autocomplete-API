# Google Autocomplete API examples (retired)

> **I've retired Google Autocomplete API, so the examples in this repo no longer work.** The repo is archived and kept for reference.
> For place lookups, use my **[Google Maps Places Scraper](https://apify.com/johnvc/google-maps-places-api?fpr=9n7kx3)** instead, and start from its example repo, [Apify-Google-Maps-Places-API](https://github.com/johnisanerd/Apify-Google-Maps-Places-API).

## Use instead

- **[Google Maps Places Scraper](https://apify.com/johnvc/google-maps-places-api?fpr=9n7kx3)**: search Google Maps by keyword and location for business names, addresses, phone numbers, ratings and coordinates. Example repo: [Apify-Google-Maps-Places-API](https://github.com/johnisanerd/Apify-Google-Maps-Places-API).

- **[Google Jobs](https://apify.com/johnvc/google-jobs-scraper?fpr=9n7kx3)**: listings with salaries and apply links, or [pay per job](https://apify.com/johnvc/google-jobs-scraper---pay-per-result?fpr=9n7kx3)

Same deal as everything else I build: clean JSON, pay per result, no monthly rental. All are MCP-ready, so Claude, Cursor and ChatGPT can call them as tools.
